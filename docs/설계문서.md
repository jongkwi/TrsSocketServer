# TrsSocketServer 설계 문서

> 초기 골격. 소스 분석이 진행되면 각 절을 채웁니다.

## 1. 시스템 개요
- CTI 미들웨어 소켓 서버 (MFC 다이얼로그 앱, 트레이 상주)
- 클라이언트 유형(`MyDefine.h` SOCKTYPE_*): WEB(1), SYS(2), AGT(3, 상담원), PBX(4, 교환기)
- 호분배 모드(CALL_DIV_*): 순차(0), 대기시간(1), 그룹단위 대기시간(2)

## 2. 클래스 구조
| 클래스 | 상속 | 역할 |
|---|---|---|
| CTrsSocketServerApp | CWinApp | 앱 진입 |
| CTrsSocketServerDlg | CDialog | 메인 UI, 타이머(TimeSyncProc), 리스트 출력(PrintListProc) |
| CListenSocket | CAsyncSocket | TCP accept |
| CClientSocket | CAsyncSocket | 클라이언트 세션 수신/송신 |
| CUdpSocket | CAsyncSocket | UDP |
| CDirectODBC | CCmdTarget | ODBC DB 접근 |
| CAlramWeb | - | 웹 알람 |
| CSystemTray | CWnd | 트레이 |
| CURLEncode | - | URL 인코딩 |

## 3. 명령 코드 (MyDefine.h)
| 범위 | 의미 |
|---|---|
| AGENT_CMD_* (0~14) | 상담원 로그온/로그아웃/전화 제어 |
| SYS_CMD_* (31~33) | 시스템 전화 제어 |
| LINK_* (41~48) | 연동 서버 메시지 (CallID, 콜수, 호분배 결과) |
| CTI_CALLCNT / GROUP_CALLCNT (51~52) | 콜 카운트 |

## 4. 데이터 흐름
- (분석 예정) Listen → Accept → ClientSocket OnReceive → 명령 파싱 → DB/연동 서버 처리 → 응답

## 5. 설정
- `TRSSocket.ini`: LINK_SERVER, BLOCK_IP, USER_LIC
- 코드 내 `APP_LOCAL_PATH = ".\NcMiddle.ini"` 참조 존재 → 실제 사용 여부 확인 필요
