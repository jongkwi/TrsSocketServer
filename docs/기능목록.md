## 0. 프로그램 정체 요약
콜센터 사이트 **감시·알람 중계 서버**. (초기 추정했던 CTI 호분배 미들웨어가 아님 — `MyDefine.h`의 CTI 정의는 전부 미사용 **[확인]**)
1. TCP 6321: IPCS 클라이언트 라이선스(실행 허가) 확인 → `Run`/`Close`
2. UDP 5363: 사이트 감시 에이전트의 장애/복구 이벤트 수신 → 알람 클라이언트(TCP 6770)·웹푸시·알림톡·이메일 전달, ACK echo
3. 5초 주기: 링크 데이터(LINK_CHECK) 21분 미수신 사이트 감지 → 장애 알림
4. 모든 상태는 MSSQL `NASA_License` DB(`ipcs_log` DSN)에 저장, 알림톡은 PostgreSQL 큐 테이블에 INSERT
